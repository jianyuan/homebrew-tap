# jianyuan/tap

Homebrew formulae and casks maintained by [@jianyuan](https://github.com/jianyuan).

## Install

```sh
brew install jianyuan/tap/<formula>
```

Or tap once, then install by name:

```sh
brew tap jianyuan/tap
brew install <formula>
```

Or in a `Brewfile`:

```ruby
tap "jianyuan/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or [Homebrew's documentation](https://docs.brew.sh).
